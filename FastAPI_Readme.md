
# So startest du die **API** lokal:

	1. Erstelle eine virtuelle Umgebung: python -m venv venv
	2. Aktiviere sie:
		○ Windows: venv\Scripts\activate
	3. Starte den Entwicklungsserver: uvicorn main:app --reload
	4. Öffne die automatische, interaktive Dokumentation im Browser: [http://127.0.0.1:8000/docs]
	5. Öffne die UI im Browser: [http://127.0.0.1:8000/ui]
**STRG+C** beendet den Entwicklungsserver
