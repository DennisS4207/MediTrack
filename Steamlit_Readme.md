
# So startest du die **API** lokal:

	1. Erstelle eine virtuelle Umgebung: python -m venv venv
	2. Aktiviere sie:
		○ Windows: venv\Scripts\activate
	3. Starte den Entwicklungsserver: streamlit run frontend/app.py
	4. Öffne die automatische, interaktive Dokumentation im Browser: 
            Local URL: http://localhost:8501
            Network URL: http://192.168.178.23:8501
**STRG+C** beendet den Entwicklungsserver
